# BDPA-RACC-MAXArm-Template-Code
### Updated 5/12/2026
HiWonders ESP32 API calling is outdated on a few of their Projects. This Repository is a refurbishment compatible with the 3.3.8 ESP32 core and this version uses the newer LEDC API

## Arduino Set up
Be sure to select the correct instance of the Board in arduino.

- Arduino CLI - `esp32:esp32:eps32`
- Arduino IDE - `ESP32 Dev Module`
